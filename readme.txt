== Description ==

A quiet, ink-and-washi block theme for sushi bars and omakase counters. Patterns for a hero, the omakase experience with its own reservation button, the full menu with prices and a Contains line on every item, the raw or undercooked advisory and an allergy notice, takeout sets with an order button for your own ordering page, the chef, and opening hours with a live open-now line, all editable in the Site Editor.

Shari Lite is a block theme: every page, header and footer is edited in the Site Editor, with no page builder. The front page is built from patterns you can rearrange, and each section is also in the pattern inserter for any page.

A contact form is plugin territory: for a form on your contact page, install a form plugin from WordPress.org.

The full version of Shari adds a one-click demo import (pages, menu, photos and journal posts), a WooCommerce shop set up with products and photos, a dark style and a setup guide: https://checkout.freemius.com/theme/43596/plan/76692/

== Frequently Asked Questions ==

= Does the theme collect any data? =

No. Shari Lite sets no cookies and uses no tracking. To offer updates it asks GitHub (api.github.com) for the latest release of github.com/allanninal/shari-lite, at most twice a day; that request carries nothing about your site. The upgrade notice in the dashboard is a plain link; dismissing it is stored on your own site.

= How do I update it? =

Like any theme: new versions appear under Dashboard › Updates. Each version is also a release at https://github.com/allanninal/shari-lite/releases, with the theme zip attached. Install that zip, not GitHub's "Source code" download, whose folder name is different.
